# Course colors

Give calendar courses consistent colors using a helper based on the course ID.
Use light backgrounds with readable dark text and matching colored borders.
Keep the same color on every meeting day and when courses are added or removed.
Show matching color markers beside course-plan details, including courses with
no meeting time. Keep course numbers and titles so color isn't the only cue.

Test color consistency across days and selection changes, plus text contrast.
