# Search courses

Add a search box above the cards to search by course number or name.
Update results while typing, ignoring capitalization and outer spaces.
Search only the selected term. Add a Clear button and a no-results message.
Keep selected courses saved even when the search hides them.

Test number/name searches, clearing, switching terms, and keeping selections.
