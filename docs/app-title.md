# Change the app title and icon

Change the browser tab title to "CS Course Scheduler" in index.html.
Use a calendar icon from React Icons and customize it with a purple background
and a white calendar so it is easy to recognize as a scheduling app.
Save the icon as public/calendar.svg and link to it from index.html.
Keep the course list the same. Check that the app builds and the title and
favicon link are correct.
