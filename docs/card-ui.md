# Make a Card UI with Tailwind

Change the course list into cards using Tailwind CSS.
Keep the current schedule title and course data.

- Show each course's term and number at the top, its title in the middle,
  and its meeting times at the bottom.
- Use white cards with rounded gray borders, padding, and a line above the
  meeting times. Use a simple sans-serif font.
- Arrange the cards in a grid that fills the available width and wraps onto
  more rows on smaller screens.
- Keep cards in the same row the same height, with matching spacing and
  meeting times lined up at the bottom.
- Keep the page usable on narrow phone screens without horizontal scrolling.

Use [the sample image](./card-ui.png) as a styling reference.
Check the layout at phone and desktop widths and run the build and lint checks.
